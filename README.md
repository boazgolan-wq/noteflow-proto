# NoteFlow – אב טיפוס ללימוד פסנתר (השם מוגדר ב-js/config.js)
אפליקציית רשת (HTML/CSS/JS + Web Audio) מותאמת לנייד, בלי ספריות חיצוניות.
## מבנה
- `index.html` – מסך ראשי ומסך משחק (כולל CSP)
- `css/style.css` – עיצוב RTL כהה
- `js/audio.js` – סינתזת צליל פסנתר ב-Web Audio
- `js/app.js` – מקלדת 2 אוקטבות (מולטי-טאץ'), תווים נופלים, ניקוד, התקדמות
- `lessons/lessons.json` – שיעורים (מנגינות מקוריות בלבד)
## הרצה
`python3 -m http.server 8080` בתיקייה, ואז לפתוח http://localhost:8080
## תכונות
מתחילים (4) ומתקדמים (3), פתיחה מדורגת, 3 ראשונים חינם והשאר "פרימיום" (מקום שמור בלבד).
ניקוד: מושלם/טוב/פספוס, דיוק %, כוכבים, קומבו. התחל/השהה ושליטה במהירות.
## עידוד
הודעות קצרות ומגוונות: כל 8 תווים ברצף, סיום שיעור, דיוק מושלם ופתיחת שיעור. לכל היותר אחת ל-4 שניות.
## שפות
js/i18n.js: he, en, es, fr, de, ar, ru, zh, pt, it, ja, hi, tr. זיהוי אוטומטי לפי שפת הדפדפן, ימין-לשמאל לעברית ולערבית, ברירת מחדל אנגלית. אפשר לכפות עם ?lang=xx.
## בהמשך
עטיפה לאפליקציה עם Capacitor ל-iOS ול-Android.
